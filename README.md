# DoNext V2.11.4

Manual weight override and actual-result progression release.

## V2.11.4 focus
- The recommended weight is shown directly in one editable weight field for each exercise.
- User can change that same weight field before logging sets; no separate “actual weight” field is shown.
- Saved workouts retain recommended weight and actual weight.
- Future recommendations use the actual weight from the latest completed workout.
- Existing V2.11.2 local-first, draft persistence, and event-driven sync behavior is retained.


## V2.11.4
- Historikposter är klickbara och öppnar detaljer för exakt genomfört pass.
- Detaljvyn visar övningar, faktisk vikt, reps per set, målintervall, rekommenderad vikt när den finns, kommentarer och passkommentar.
- V2.11.3:s enda redigerbara viktfält och progression är oförändrade.
